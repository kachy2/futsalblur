# 풋살블러(FutsalBlur) — 경기 영상 속 얼굴을 브라우저에서 흐리게

[English](README.md) · **앱 열기: https://kachy2.github.io/futsalblur/ko/**

경기 영상(삼각대에 올린 폰으로 찍은 풋살·축구 등)에서 선수들의 머리를 찾아 흐리게 하는 무료 오픈소스 도구입니다.
누가 누구인지 알아보지 못하게 하면서도 경기 흐름은 그대로 볼 수 있게 하는 것이 목표입니다.

- **설치 없음** — 브라우저에서 동작합니다(PC의 Chrome/Edge 권장)
- **업로드 없음** — 영상은 기기 밖으로 나가지 않습니다. 검출, 흐림, 저장 모두 브라우저에서 합니다
- **조절 가능** — 검출 점수 기준(0.05 / 0.1 / 0.2 / 0.25 / 0.3 프리셋 또는 원하는 값, 기본 0.25), 흐림 크기, 강도, 흐림/모자이크
- **검출 결과 내보내기** — 검출기가 찾은 상자를 JSON으로 내려받아 다른 곳에 쓸 수 있습니다

머리 검출기는 제작자가 직접 찍은 영상에, 공개 라이선스 모델로 만든 라벨을 붙여 학습했습니다. 기본 설정에서
시험 프레임 4,056장의 얼굴 99.7%를 흐렸고, 흐린 면적은 화면의 0.5%였습니다. 만든 방법, 측정 방법, 한계는
[모델 카드](web/public/models/NOTICE.md)(영문)에 있습니다.

## 사용법
1. 영상(MP4/MOV)을 고릅니다.
2. **머리 찾기**를 누르고 기다립니다(긴 4K 영상은 오래 걸리니 먼저 짧은 클립으로 해 보세요).
3. 미리보기에서 프레임을 확인하며 점수 기준과 흐림을 조절합니다.
4. **흐린 영상 저장**을 누릅니다. 소리는 그대로 복사됩니다.

공유하기 전에 결과를 꼭 확인하세요. 어떤 검출기도 모든 얼굴을 찾지는 못합니다. 작거나 멀거나 가려진 얼굴은 놓칠 수 있습니다.

## 동작 방식
1. WebCodecs로 모든 프레임을 디코딩합니다. 세 프레임마다 1080p 수준(4K 기준)으로 줄여 96 px씩 겹치는 640 px 타일로
   나누고, 작은 머리 검출기(D-FINE-N을 "머리" 한 종류로 미세조정)를 타일마다 돌립니다. 그래픽 칩(WebGPU)이 빠르면
   그것을, 아니면 CPU 스레드(WebAssembly)를 씁니다.
2. 상자를 프레임 사이로 이어서, 사이 프레임에는 보간한 상자를 쓰고 한 번 놓친 머리는 직전 상자를 유지합니다.
3. 저장할 때 영상을 다시 디코딩해 넓힌 상자마다 가장자리가 부드러운 타원 흐림을 넣고 H.264 MP4로 인코딩합니다.

## 개발자용
- `web/` — Svelte 5 + Vite 앱(분석·저장 worker, 참조 도구와 결과를 맞춘 TypeScript 핵심 코드)
- 시험 — `npm test`(Vitest), `npx playwright test`(헤드리스 Chrome 종단 시험)
- 빌드 — `npm run build` (모델은 `web/public/models/head.onnx`, 다른 모델은 `HEAD_ONNX=<model.onnx>`)
